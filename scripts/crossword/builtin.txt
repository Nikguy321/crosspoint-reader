# Format: "=== <id> | <title>", then the grid rows (A-Z letters, '#' = block), then one "A <n> <clue>" per
# Across entry and one "D <n> <clue>" per Down entry. A comment is '#' alone or '#' then a space and text (a line
# like '#note' or '#####' is NOT a comment: it is an error or a grid row); blank lines are ignored.
#
# Every grid and every clue here is original to this repository and released under its MIT license. The grids were
# filled by scripts/crossword/fill (a deterministic backtracking filler) using fill candidates from the MIT-licensed
# Collaborative Word List (https://github.com/Crossword-Nexus/collaborative-word-list), filtered by allow/deny lists
# picked in review; the clues were written fresh for this repo. No published puzzle or clue data was used.
